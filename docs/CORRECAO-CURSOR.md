# Cursor padrão

O cursor personalizado foi retirado do App. A regra antiga que escondia o cursor em toda a área do jogo foi removida. Uma regra final usa cursor auto nos vagões de todas as cores, computador, interações e cenas. Nenhuma mecânica de piano, roteiro ou save foi modificada.

Arquivos alterados: frontend/src/App.jsx, frontend/src/styles/worldUnified.css, frontend/src/styles/mediaRevision.css. Teste: frontend/tests/cursor-smoke.js. Build portátil regenerado e verificação de estilos executada no JavaFX.
